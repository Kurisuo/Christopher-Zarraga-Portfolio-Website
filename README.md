# My CS Journey

I want to build a personal website to showcase my work as a Computer Science student. The layout I have in mind goes as follows: 1) Introduction of photo of myself on the left hand side, the right side is a short bio of myself and bullet points of some examples of work i have done and hobbies. 2 - scrolling down) story of first project i built in replit  and how i came to love with the project code snippet / example embedded in CS. 3 - scrolling down) story of how i got into UCSC through a full-ride first in the universities history and decided to major in CS with applied math - showcase two projects built during school (including talking about NVIDIA hackathon i did on campus and built NVPilot - showcase NVPilot snippet here). 4 - scroll down) showcase rest of projects and talk about current pursuits.  5 - scroll down; contact information + resume + github
